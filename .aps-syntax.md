# APS Syntax v26.8.24

APS is a protocol for knowledge-work reconstitution and lawful manufacture.

## Core equation

```text
A = mu(O*)
```

- `O*`: admitted, bounded knowledge.
- `mu`: admitted manufacturing law.
- `A`: manufactured artifact or consequence with only evidence-earned standing.

## Canonical transition

```text
predecessor / reality
  -> OBSERVE
  -> ADMIT O*
  -> CONTRACT
  -> DfCM candidate strategies + candidate falsifiers
  -> SELECT
  -> CONSTRUCT
  -> authority admission / refusal
  -> DO
  -> process events + receipts
  -> independent VERIFY
  -> STANDING
  -> reusable knowledge
  -> SUNSET / RECONSTITUTE
```

`SELECT`, `CONSTRUCT`, and `DO` are distinct authority classes. No plan, model output, generated artifact, CLI invocation, transport message, or executable receives ambient `DO` authority.

## Standing

```text
ALIVE
PARTIAL_ALIVE
BLOCKED
BUILD_BROKEN
UNKNOWN
UNSUPPORTED
REFUSED
```

`REFUSED` is a valid successful safety outcome when the requested transition is inadmissible. `UNKNOWN` is never success.

## Constitutional law

2. Preserve truth, not implementations.
3. Zero continuation privilege.
4. Zero uninformed elimination.
5. Contract before implementation.
6. Known pattern before novel mechanism.
7. ggen-first manufacture, including generated tool and CLI invocation.
8. No ambient DO authority.
9. Zero unreceipted actuation.
10. No prose outranks evidence.
11. Governance scales with law, not artifact count.
