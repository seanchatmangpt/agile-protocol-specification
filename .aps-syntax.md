# APS Syntax v26.8.24

APS is a protocol for knowledge-work reconstitution and lawful manufacture.

## Core equation

```text
A = mu(O*)
```

- `O*`: admitted, bounded knowledge.
- `mu`: admitted manufacturing law.
- `A`: manufactured artifact or consequence with only evidence-earned standing.

## Canonical transition

```text
predecessor / reality
  -> OBSERVE
  -> ADMIT O*
  -> CONTRACT
  -> DfCM candidate strategies + candidate falsifiers
  -> SELECT
  -> CONSTRUCT
  -> authority admission / refusal
  -> DO
  -> process events + receipts
  -> independent VERIFY
  -> STANDING
  -> reusable knowledge
  -> SUNSET / RECONSTITUTE
```

`SELECT`, `CONSTRUCT`, and `DO` are distinct authority classes. No plan, model output, generated artifact, CLI invocation, transport message, or executable receives ambient `DO` authority.

## Compact operator glyphs (v26.9.17)

Defined single-glyph opcodes compress the manufacturing HTN. A glyph is
binding ONLY through this mapping plus a repo-side enforcement anchor;
the glyph itself carries no authority.

```text
守  preserve        predecessor state and lawful options; never destroy admissible structure
柵  fence           boundary that fails closed; unknown reversibility is a fence
算  calculate       lawful manufacture over O* under mu
除  exclude         alternatives dropped are recorded; silent pruning is forbidden
偽  falsify         adversarial input is manufactured before the claim
延  extend          existing family before new pack
実  operationalize  promote into ontology, policy, generator, verifier, or process control
```

Canonical chain:

```text
SOLVE(x) -> 守 -> 柵 -> 算 -> 除 -> 偽 -> 延 -> 実
```

Recoverability law:

```text
glyph != binding            : mapping must be defined here
unicode chars != model tokens != semantic information
utility ~= (semantic_density * recoverability) / ambiguity
constraint: P(misparse) < epsilon
recoverability ~= P(behavior | symbol lost)
```

The last line is the externalization invariant: any glyph used in operating
law must keep a repo-side anchor (test, gate, or shape) so behavior survives
the loss of the prompt that introduced it.

```text
capacity = f(model_tier, agent_weight)     # measured, never assumed
```

Trivial single-tool agents carry near-zero request density and may run 20+
concurrently; heavyweight multi-turn agents are the pacing subject.
