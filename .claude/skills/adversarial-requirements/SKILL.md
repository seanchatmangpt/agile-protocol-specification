# Adversarial Requirements

Treat credible criticism as unexplored state space. Convert each objection into a candidate falsifier before turning it into a requirement.

High-value families include catastrophic consequence, authority attribution, long-horizon reconstruction, process fitness, artifact-scale governance, reproducibility, model/session disappearance, liability, and unsafe-but-conformant processes.

A criticism becomes architecture only after its failure condition is explicit and evidence shows the requirement is necessary.
