# Reference Manufacturing Stack

APS is a protocol and constitutional model, not a dependency on one repository or technology. Existing Chatman-ecosystem projects are useful as reference implementations of distinct manufacturing roles, but every implementation remains replaceable under Chatman's Law.

## Role decomposition

A reference end-to-end stack can be understood as:

```text
intent / observed reality
  -> intent-to-semantics admission
  -> accumulated executable knowledge
  -> deterministic manufacturing kernel
  -> specialized generator/tool composition
  -> typed interaction/protocol surfaces
  -> executable application/platform/process projections
  -> authority-bound consequence
  -> evidence + process intelligence
  -> reconstitution / learning
```

The important object is the role boundary, not the current repository name.

## Preserve fences

Several fences prevent a manufacturing ecosystem from collapsing back into a monolith:

- semantic authority is not transport;
- marketplace knowledge is not runtime actuation;
- planning is not DO;
- a generator is not its verifier;
- a protocol adapter is not business truth;
- application framework state is not permanent enterprise semantics;
- process observation is not permission to change the process;
- archive evidence is not current authority.

The more capable the factory becomes, the more important these fences become because artifact volume can hide accidental authority transfer.

## The kernel should shrink relative to knowledge

A mature manufacturing system should move reusable knowledge out of bespoke runtime mechanism and into admitted semantic/manufacturing assets.

The target shape is:

```text
small reconstitutable kernel
  + large accumulated executable knowledge graph
  + qualified downstream capital equipment
  + independent metrology
```

rather than an ever-growing hand-authored generator monolith.

## Self-manufacture and fixed point

A strong future qualification target is:

```text
ggen_0
  -> manufacture ggen_1 from admitted manufacturing knowledge
  -> run ggen_1
  -> manufacture ggen_2
  -> independently qualify the declared fixed-point boundary
```

The exact boundary may be byte identity, behavioral equivalence, command-surface equivalence, authority/evidence equivalence, or a declared combination. These claims must not be conflated.

## Ecosystem capital accumulation

The stack compounds when each successful novelty moves upstream:

```text
one-off observation
  -> explicit contract
  -> candidate reusable pattern
  -> independent falsification
  -> marketplace admission
  -> deterministic remanufacture
```

This changes the economic role of a repository. A repository is not valuable merely because it contains working code; it is valuable when it contributes reusable manufacturing knowledge, irreducible mechanism, independent evidence, or a qualified boundary the wider factory can repeatedly exploit.

## Reference implementations are themselves sunk

No named project in this chapter is exempt from reconstitution. If a successor can recover its required truth and provide superior qualified consequences, APS predicts the current implementation should become archive evidence and reusable knowledge rather than permanent infrastructure.
