# APS self-manufacturing contract

APS v26.8.24 admits the following bounded self-application:

```text
APS mdBook identity + navigation RDF
  -> exact ggen-marketplace mdbook-pattern-language-pack
  -> exact ggen v26.8.21 runtime
  -> SUMMARY.md + core book.toml projection
  -> ggen receipt verification
  -> second manufacture
  -> byte-identity court
  -> APS repository qualification
```

The knowledge graph is authoritative for the fields covered by this contract. `specification-guide/src/SUMMARY.md` is inventory: a deterministic projection that must be reproducible by the pinned ecosystem.

APS-specific presentation settings in `specification-guide/book.toml` are currently an admitted residual extension beyond the marketplace pack. CI compares all book identity/build fields that the pack manufactures while preserving those APS-specific presentation settings.

This is a real but bounded jig advancement. It proves that a reusable marketplace manufacturing pattern can manufacture an active APS control surface with verified replay. It does not claim that every APS chapter, ontology, contract, verifier, or workflow is already self-manufactured.
