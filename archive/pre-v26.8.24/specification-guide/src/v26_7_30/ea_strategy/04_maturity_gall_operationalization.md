## Named falsifier

The Enterprise Architecture as Strategy claim is false at a coordinate if a material change cannot be traversed through the same objects and evidence from:

```text
strategy
-> operating model
-> capability and value stream
-> core diagram
-> information and application realization
-> GBB and pack closure
-> baseline/target/transition
-> work-order authority
-> manufactured artifact or intent
-> independent verification
-> execution grant
-> observed consequence
-> receipt
-> replay
-> architecture revision
```

A successful adjacent workflow does not satisfy the chain. A persuasive architecture document does not satisfy it. A generated deployment without business-capability identity does not satisfy it. A formal theorem without implementation correspondence does not satisfy it. A deployment without required telemetry and receipts does not satisfy it.
