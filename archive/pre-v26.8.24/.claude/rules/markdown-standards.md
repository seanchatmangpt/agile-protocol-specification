# Markdown Standards for APS

When working with Markdown files in this repository:

## Formatting Rules

1. **Single H1**: Each file has exactly one `#` heading at the top
2. **Heading Hierarchy**: Use `##`, `###`, `####` in order (don't skip levels)
3. **Line Length**: Prefer lines under 120 characters for readability
4. **Separators**: Use `---` to separate major sections
5. **Code Blocks**: Always specify language (```bash, ```yaml, ```markdown)

## Content Structure

1. **Introduction First**: Start with a paragraph explaining the document's purpose
2. **Logical Sections**: Group related content under clear headings
3. **Conclusion Last**: End with summary or key takeaways when appropriate

## Linking

1. **Relative Links**: Use relative paths for internal links
2. **Descriptive Text**: Make link text meaningful (not "click here")
3. **Verify Links**: Ensure all internal links point to existing files

## Lists

1. **Consistent Markers**: Use `-` for unordered lists
2. **Numbered When Ordered**: Use `1.` only when sequence matters
3. **Parallel Structure**: Keep list items grammatically consistent
