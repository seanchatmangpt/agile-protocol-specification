# Build Documentation

Build the Agile Protocol Specification mdBook documentation.

## Instructions

1. Navigate to the specification-guide directory
2. Run `mdbook build` to generate HTML output
3. Report any build errors or warnings
4. Confirm successful build with output location

```bash
cd specification-guide && mdbook build
```

The built documentation will be available in `specification-guide/book/`.
